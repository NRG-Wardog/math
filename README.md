# Mathematics and formal proofs

A collection of mathematical statements, supporting notes and Lean formalizations.

- [CONTENTS.md](CONTENTS.md) — index of statements and status
- [lean/](lean/) — executable formalizations, with a pinned Lean toolchain
- [preprints/](preprints/) — mathematical statements and proof notes
- [history.md](history.md) — verification history

Each entry is labeled with its actual verification scope. A conditional or general theorem is not a proof of an external implementation.

The repository layout is inspired by [openai/math](https://github.com/openai/math); it is independent and does not represent OpenAI.
